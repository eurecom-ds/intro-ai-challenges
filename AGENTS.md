# Challenge repository instructions

Keep challenge implementation, instructor tools and documentation in this
repository. Read README.md and the affected activity's guide before editing.

## Documentation rule

All Markdown must be self-contained and describe the subject, current behavior,
methods or results.

- Do not include local filesystem paths, private artifact locations or
  machine-specific directory layouts.
- Do not include provenance from chats, prompts, agent activity, workspace
  history, execution logs, document production or migration work.
- Link to committed files using repository-relative links. Use named environment
  variables or explicit placeholders for storage supplied by the reader.
- Preserve scientific methods, results, necessary source citations and license
  attributions.
- Check all affected Markdown for these rules before committing.
